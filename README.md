# Freezer

Kill switch для программ на macOS. Если внешний IP не из разрешённых стран (упал VPN, сменилась сеть, утечка IPv6), выбранные программы замораживаются (`SIGSTOP`). Когда IP снова правильный, они оживают (`SIGCONT`). Если разрешённый IP не вернулся за заданное время, программы закрываются (`SIGKILL`).

Swift 6, SwiftUI, macOS 15+. Приложение есть и в Dock, и в строке меню.

- **Строка меню:** цветной щит со статусом и, на выбор, флаг со страной или IP-адрес рядом с ним (Настройки → Поведение → Вид).
- **Dock:** клик по значку открывает настройки, правый клик даёт статус, «Проверить IP», паузу. Красный бейдж показывает, сколько программ заморожено. Значок можно убрать из Dock в настройках.

## Сборка и запуск

```bash
Scripts/compile_and_run.sh          # собрать Freezer.app, перезапустить, проверить, что живо
Scripts/compile_and_run.sh --test   # то же, но сначала тесты
swift test                          # только тесты
```

`Freezer.app` появляется в корне репозитория. Чтобы установить приложение, перенесите его в `/Applications`.

Иконка (`Icon.icns`) генерируется скриптом: `swift Scripts/make_icon.swift`.

Раньше приложение называлось Karing. При первом запуске Freezer переносит конфиг из `~/Library/Application Support/Karing/` и ручные заморозки.

## Как устроено

| Где | Что |
|---|---|
| `Sources/FreezerCore/IPProbe.swift` | IPv4 спрашивается у 4 сервисов, IPv6 у 3, страна определяется через ipinfo.io → country.is → ipapi.co |
| `Sources/FreezerCore/Policy.swift` | Чистая логика: консенсус сервисов, вердикт (fail-closed), таймер «заморозить → закрыть» |
| `Sources/FreezerCore/Processes.swift` | Список процессов (`sysctl`), сопоставление с правилами, потомки, сигналы |
| `Sources/FreezerCore/NetworkChangeMonitor.swift` | Смена интерфейсов и шлюзов (`NWPathMonitor`) |
| `Sources/Freezer/GuardEngine.swift` | Цикл проверок, сон и пробуждение, пауза, применение сигналов |
| `Sources/Freezer/*View.swift` | Меню в строке меню и окно настроек |

Настройки хранятся в `~/Library/Application Support/Freezer/config.json`.

## Поведение

- **Пока нет подтверждённого IP, программы заморожены:** при старте, после смены сети, после пробуждения, при расхождении сервисов.
- **Сон.** Перед сном программы замораживаются, после пробуждения отпускаются только после проверки IP.
- **Выход из Freezer** (меню, `SIGTERM`, выход из системы) размораживает всё.
- **Если Freezer упал,** программы остаются замороженными. Это fail-closed. При следующем запуске и разрешённом IP Freezer их отпустит.
- **Safari защитить нельзя:** его вкладки работают в общих системных процессах.

## Утечка DNS

Freezer спрашивает `whoami.akamai.net` через системный резолвер (как это делают сами программы). Ответ — адрес, с которого DNS-резолвер ходит в интернет. Утечкой считается случай, когда страна этого адреса не входит в разрешённые и не совпадает со страной внешнего IP. Обычно так бывает, если трафик идёт через VPN, а DNS остался у провайдера.

Режимы (Настройки → Поведение → «Утечка DNS»): выключено, предупреждать (по умолчанию), замораживать. Если страну резолвера определить не удалось, утечкой это не считается.

## Ручное управление

В меню и в настройках у каждой программы есть кнопки:

- **❄︎ Заморозить:** программа стоит при любом IP, пока её не разморозить. Ручная заморозка переживает перезапуск Freezer. При выходе из Freezer программа размораживается, а при следующем запуске снова замерзает.
- **▶︎ Разморозить:** снимает ручную заморозку. Если программа заморожена из-за чужого IP, она работает до конца блокировки (бейдж «отпущено»).
- **✕ Убить:** немедленный `SIGKILL` всем процессам программы, с подтверждением.

Кнопка «+ Заморозить» в меню замораживает любую запущенную программу, даже если её нет в списке защиты.

## Снимки UI (debug)

```bash
swift build && .build/debug/Freezer --render-snapshots /tmp/freezer-shots
```

Команда рисует меню и вкладки настроек на тестовых данных (светлая и тёмная тема) в PNG. Проверки и сигналы при этом не запускаются.
